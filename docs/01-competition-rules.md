## 6. 报名方式

在官方活动仓库以 **Issue** 形式提交，正文标准格式：

```text
【参赛申请】
项目名称：{项目名称}
项目地址：{项目 GitHub 仓库地址}
项目简介：{项目简介}
```

- Issue 内容 **不得超过 1000 字**，且 **不要携带图片**，否则可能报名失败
- 报名成功后系统会在该 Issue 下回复成功通知；失败也会回复具体原因，修改后可重新提交
- 提交即视为授权麦当劳通过 GitHub 开放接口读取项目必要目录与文件

## 7. 排名与评选机制

**评选依据 = GitHub 公开 Star 数**（不是技术评审打分）。

- 定时采集报名成功项目的公开 Star 数据
- **Star = 0 不进入排行榜**
- 原则上取前 100 名；第 100 名若存在并列，所有并列项目全部进入（可能超过 100 个）
- 并列排名占用相应名次，后续名次顺延；并列者均可获得该名次对应奖励
- **同一 GitHub 账号多个项目，仅 Star 最高的项目进入排行榜**；Star 相同则取最早提交申请者
- 最终排名以 **2026-10-26 00:00** 累计公开 Star 为准，**活动开始前已获得的 Star 也计入**
- 活动期间严禁刷榜、机器人刷 Star、多账号串通等不正当手段，否则取消资格

> 📌 对本项目的直接影响：排名完全由 Star 决定，**README 的展示质量、项目传播性和演示视频/GIF 的观感，其重要性不低于技术实现本身**。这一点必须写进产品策划。
