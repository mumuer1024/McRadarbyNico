### 实测新增的工程约束（写代码前必须记住）

1. **金额单位**：`query-meals` 用**元**（字符串），`calculate-price` 用**分**（整数）→ 封装层统一换算
2. **`canWithOrder` 陷阱**：`canWithOrder=true` 的餐品其 `currentPrice` 需随单购会员卡，默认排除或强制标注
3. **券不可叠加**：`600022 暂不支持多张券使用` → 逐券试算取最优
4. **🆕 订单状态只能看文本**：实测 `status:"40"` 与官方注释枚举（1/2/4/6/7/8/10）不符 → **只用 `orderStatus` 中文文本判断**
5. **🆕 `create-order` 入参 ≈ `calculate-price` 入参 + `takeWayCode`** → 算价请求体可直接复用为下单骨架
6. **🆕 支付时限 15 分钟**（`expirePayTime` − `createTime`）→ 需做倒计时提示
7. **🆕 `create-order` 失败/超时绝不自动重试** → 先 `order-list` 核对，防重复单
8. **🆕 `auto-bind-coupons` 是批量接口，无单张领取** → 话术必须说清
9. **🆕 券池存在同名重复批次** → 领券前后对比不能用券名做唯一键

## 3. MCP 调用封装策略

### 3.1 统一入口

```python
call_mcp(tool_name, params, *, risk_level="safe", timeout=15) -> Result
```

- 所有工具走同一入口，便于统一处理鉴权、错误、限流、日志
- `risk_level` 由 `safety.py` 校验：`safe` 可直接执行；`sensitive` 首次需授权；`dangerous` 必须双确认

### 3.2 关键策略

| 策略 | 实现 |
|---|---|
| 鉴权 | Token 由**用户在 AI 客户端侧**自行配置（模板为 `Authorization: Bearer <你的_MCP_TOKEN>`）；本项目不读取、不硬编码、不落盘 |
| 重试 | 5xx / 网络错误退避重试 2 次；4xx 不重试 |
| 限流 | 本地令牌桶，硬上限 300 次/分钟（官方 600 的一半，留余量）；429 后立即休眠 |
| 缓存 | 菜单 30 min、券池 10 min、活动 6 h；下单前强制刷新价格 |
| 错误处理 | 结构化异常（`MCPAuthError` / `MCPRateLimitError` / `MCPToolError`），上层按类型降级 |
| 超时 | 默认 15 s，价格计算 20 s |
| 日志 | 只记录工具名、耗时、成功/失败码；**参数与返回体中的敏感字段脱敏** |
| 降级 | 任一关键调用失败 → 明确告知用户 + 给出"稍后重试"，不静默兜底、不编造数据 |

### 3.3 调用编排

- **并行**：菜单、券池、活动三者无依赖 → 并行拉取，减少等待
- **串行**：定位门店 → 拿菜单 → 生成候选 → 精算 → 渲染（存在依赖）
- **批量控制**：单次盲盒精算候选数 ≤ 5，避免撞限流


> 这样既满足"提醒"需求，又保持 Skill 零后台依赖，符合"维护简单"的要求。

## 6. 依赖安装方案

| 依赖 | 用途 | 方案 |
|---|---|---|
| Python 3.13 | 脚本运行 | 使用本机可用的 Python 解释器（`python` / `python3`；用 `where python` 或 `which python3` 查路径）。实测环境为 3.13 |
| `requests` 或 `httpx` | MCP 调用 | **优先评估能否用标准库 `urllib`**；若需 HTTP/2 或复杂 SSE 解析再引入 |
| MCP SDK | 协议封装 | **先不用**。Streamable HTTP 协议很简单（POST JSON + `Authorization` 头），自己封装 200 行足够，避免引入重依赖与版本风险 |
| 其他 | — | **不引入**。组合算法用标准库 `random`/`itertools` 即可 |

## 7. 测试策略

### 7.1 分层

| 层 | 内容 | 方法 |
|---|---|---|
| L1 连通 | Token 有效、工具可调用 | 手动跑 `now-time-info` |
| L2 结构 | 每个工具返回字段符合预期 | 记录到 `research/tool-test-results.md`，写 field 断言脚本 |
| L3 单元 | 组合算法、去重、预算筛选 | 用**假数据**跑（不调 MCP），保证算法正确性 |
| L4 集成 | 完整盲盒流程 | 真实调用，但**小额、少量、不落单** |
| L5 安全 | 危险工具是否被正确拦截 | 用假意图测试"确认闸门"，**未获授权前绝不真实领券/下单** |
| 🆕 L6 写操作 | `create-order` / `auto-bind-coupons` 的真实行为 | **必须经用户单独授权**，且单次、小额、可撤销 |

| # | 用例 | 期望 |
|---|---|---|
